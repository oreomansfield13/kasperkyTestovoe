Threat Exchange Service

Разработан REST-сервис для обмена информацией об угрозах
Используются: PostgreSQL и Docker

Основные моменты по ТЗ:
- Полноценный сервис для управления записями, согласно `openapi.yaml`
- Реализована строгая проверка форматов (MD5, SHA256, URL, Enum для уровней опасностей), как на уровне DTO, так и на уровне доменной модели
- Хранение данных в PostrgeSQL. Использовал `pgx/v5`, до этого с БД не работал. Также добавлено автоматическое применение миграций БД при старте приложения
- Добавлено корректное завершение работы сервера (реализовано ожидание выполнения текущих запросов при остановке)
- Реализованы юнит-тесты для покрытия бизнес-логики
- Реализована multi-stage сборка и `docker-compose` для запуска всего стека одной командой. Также, первый опыт работы с докером.
